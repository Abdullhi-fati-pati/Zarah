🐍 Python Beginner Practice

A collection of simple Python programs and exercises created while learning the fundamentals of Python programming.

📌 About the Project

This repository contains beginner-friendly Python examples covering:

- User input and output
- Variables and basic data types
- Arithmetic operations
- String methods
- Mathematical functions
- BMI calculation
- "if", "elif", and "else" statements
- Basic calculations and problem solving
- Formatted output using f-strings

📂 Programs Included

1. Basic Python Operations

Examples of:

- Addition
- Subtraction
- Division
- Floor division
- Modulus
- Multiplication
- Exponentiation

2. String Operations

The project demonstrates basic string methods such as:

- Converting text to lowercase
- Finding text within a string
- Replacing words in a string

3. Mathematical Functions

The "math" module is used to demonstrate:

- "ceil()"
- "floor()"
- "round()"
- "abs()"

4. BMI Calculator

The program accepts a user's weight and height and calculates their Body Mass Index (BMI).

The current version accepts weight in pounds and height in meters, then converts the weight to kilograms before calculating BMI.

5. Weather Condition Program

A simple conditional program asks whether the weather is hot or cold and displays an appropriate message.

6. House Down Payment Calculator

The program calculates the required down payment based on whether the user has good credit.

- Good credit → 10% down payment
- No good credit → 20% down payment

7. Life Expectancy Calculator

The program asks for the user's age and estimates the remaining number of:

- Days
- Weeks
- Months

until age 100.

🛠️ Requirements

You only need:

- Python 3.x

The programs use Python's built-in features and the standard "math" module.
